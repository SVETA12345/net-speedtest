# net-speedtest

Консольный скрипт на Node.js для замера скорости загрузки.

## Что делает

- Принимает URL (например, тяжёлая картинка или любой файл).
- Делает N запросов **последовательно**, полностью дожидаясь ответа на каждый.
- Считает среднее время запроса и общий объём скачанных данных.
- Печатает в консоль скорость скачивания.

## Единицы измерения

- **Объём**: байты, KB, MB (`1 KB = 1000 Б`, `1 MB = 1 000 000 Б`).
- **Скорость**: `MB/s` (мегабайт в секунду) и `Mbit/s` (мегабит в секунду), где `1 Mbit = 10^6 бит`.

## Требования

- Node.js >= 14 (используются только встроенные модули, внешних зависимостей нет).

## Запуск

```bash
node index.js <url> [количество-запросов]
```

По умолчанию количество запросов — **10**.

## Примеры

```bash
# тяжёлая картинка / файл
node index.js https://example.com/heavy-image.jpg

# 100 МБ тестовый файл Cloudflare
node index.js "https://speed.cloudflare.com/__down?bytes=100000000"

# своё количество запросов
node index.js https://example.com/file.bin 5
```

## Пример вывода

```
Цель: https://example.com/heavy-image.jpg
Запросов: 10

Запрос 1/10... готово: 4.92 MB за 1240 мс
...
Запрос 10/10... готово: 4.92 MB за 1215 мс

--- Результаты ---
Среднее время запроса: 1227.3 мс
Общий объём:           49.20 MB
Скорость:              4.01 MB/s (32.07 Mbit/s)
```
